# 맞춤 계산기

품목별 기준값(베이스 데이터)을 등록해 두고 쓰는 계산기입니다.
설치 없이 `index.html` 하나로 동작하며, 인터넷 연결 없이 쓸 수 있습니다.

## 기본 제공 계산기

| 계산기 | 종류 | 내용 |
| --- | --- | --- |
| 원단 길이-무게 변환기 | 환산형 | 원단 A 1m = 10g 처럼 등록 → 10m 입력 시 100g (반대 방향도 가능) |
| 고형분 계산기 | 수식형 | 고형분(%) = 건조 후 무게 ÷ 건조 전 무게 × 100, 휘발분(%) |
| 배합 고형분 계산기 | 배합형 | 원료별 고형분%와 투입량 → 배합 전체 고형분%, 총 투입량, 고형분량 |

## 새 계산기 만들기

메인 화면 **+ 새 계산기** → 종류 선택

- **환산형**: 두 단위(예: m ↔ g)와 품목별 기준값(1m 당 몇 g)을 등록합니다. 양쪽 칸 어디에 입력해도 서로 환산됩니다.
- **수식형**: 입력 칸(A, B, …)과 계산식(예: `B / A * 100`)을 직접 정의합니다. 앞의 결과(R1 등)를 다음 식에서 쓸 수 있고, `round(x, 2)`, `min`, `max`, `abs`, `sqrt`도 지원합니다.
- **배합형**: 원료별 함량(%)을 등록해 두고, 계산기에서 원료를 고르고 투입량만 넣습니다.

## 묶음

계산기를 원하는 이름의 묶음(예: 원단, 코팅액, 배합)으로 나눠 둘 수 있습니다.

- 메인 화면 위쪽 탭으로 묶음별로 보고, **+ 묶음**으로 새 묶음을 만듭니다.
- 계산기 편집 화면의 **묶음** 칸에 이름을 쓰거나 기존 묶음을 고릅니다. 카드 메뉴(⋯) → **묶음 이동**으로도 옮길 수 있습니다.
- 묶음 제목 옆 ⋯ 메뉴에서 이름 바꾸기, 순서 바꾸기, 삭제(안의 계산기는 미분류로 이동)를 할 수 있습니다.

## 품목 검색

품목(환산형)이나 원료(배합형)가 많을 때는 검색칸에 일부만 입력하면 자동완성 목록이 나옵니다.

- 초성으로도 찾을 수 있습니다 (예: `ㅋㅌ` → 코팅지, `ㅇㄷ` → 원단).
- ↑↓ 키로 고르고 Enter로 선택합니다.
- 찾는 항목이 없으면 목록 맨 아래의 **“입력한 이름” 새로 등록**으로 바로 추가할 수 있습니다.
- 품목이 많으면 칩에는 최근 사용한 6개만 보여 줍니다.

품목/원료는 계산기 화면의 **+ 추가** 버튼으로 바로 등록하거나, 편집 화면에서 엑셀 두 열(이름, 값)을 복사해 **엑셀에서 붙여넣기**로 한꺼번에 넣을 수 있습니다.

## 설치 방법

### Windows PC (권장)

1. 이 폴더 전체를 원하는 위치(예: `문서\맞춤 계산기`)에 복사합니다. 압축 파일이면 먼저 압축을 풉니다.
2. 폴더 안의 **`설치.bat`** 을 더블클릭합니다.
3. 바탕화면과 시작 메뉴에 **맞춤 계산기** 바로가기가 생깁니다. 주소창 없는 앱 창(Edge/Chrome 앱 모드)으로 열립니다.

- 폴더를 옮긴 뒤에는 `설치.bat`을 다시 실행하세요.
- 바로가기를 지우려면 `제거.bat`을 실행합니다.
- 설치 없이 쓰려면 `index.html`을 더블클릭해서 브라우저로 열어도 됩니다.

### 휴대폰 (앱으로 설치)

이 폴더를 정적 호스팅(Vercel, GitHub Pages, 사내 웹서버 등)에 그대로 올립니다. 빌드 과정은 없습니다.

1. 폰 브라우저(안드로이드 크롬, 아이폰 사파리)로 올린 주소를 엽니다.
2. 메인 화면의 **앱 설치** 버튼을 누릅니다.
   - 안드로이드: 설치 창이 바로 뜹니다.
   - 아이폰: 안내에 따라 공유 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 동작합니다.

한 번 열고 나면 오프라인에서도 동작합니다 (`sw.js`).

## 데이터 보관

- 등록한 계산기와 베이스 데이터는 **사용 중인 브라우저에 자동 저장**됩니다 (localStorage).
- 다른 PC로 옮기거나 브라우저 데이터를 지우기 전에는 메인 화면 메뉴(⋯) → **백업 파일로 내보내기**로 JSON 파일을 받아 두고, 새 환경에서 **백업 파일 불러오기**를 하세요.
- Edge로 연 것과 Chrome으로 연 것은 저장 공간이 따로입니다.

## 사용 팁

- 입력 칸에 `10+5`, `3×12.5` 같은 식을 바로 쓸 수 있습니다. Enter 또는 `=`를 누르면 결과 숫자로 바뀝니다.
- 결과 화면 오른쪽 위 복사 버튼을 누르면 숫자만 복사되므로 엑셀에 바로 붙여넣을 수 있습니다.
- 계산기 화면 상단의 키패드 버튼으로 화면 키패드를 숨기거나 다시 보이게 할 수 있습니다.
- 편집 화면에서 `Ctrl + S`로 저장할 수 있습니다.
