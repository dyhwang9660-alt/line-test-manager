## 2. 고쳐야 할 문제

### 높음: 사용자가 바로 겪는 오류

**1. 창(시트·확인창)이 열린 채 휴대폰 뒤로가기를 누르면 창만 닫히지 않고 화면 전체가 바뀜**
- 상황: 홈에서 메뉴나 종류 고르기 창을 닫으려고 뒤로가기를 누르면 앱이 꺼집니다. 계산기 화면에서 "새 품목 등록" 창을 닫으려 하면 홈으로 튕기고 적던 이름이 사라집니다(실제로 눌러 확인).
- 원인: 창을 열 때 방문 기록을 남기지 않고, 화면이 바뀌면 창을 그냥 닫습니다. `index.html:842-870`, `index.html:926`
- 고치는 방향: 창을 열 때 기록을 한 칸 추가하고, 뒤로가기가 오면 창만 닫습니다.

**2. 편집 중 휴대폰·브라우저 뒤로가기로 나가면 "저장하지 않고 나갈까요?" 없이 바로 사라짐**
- 상황: 새 계산기를 한참 만들다 뒤로가기를 누르면 확인 없이 초안이 없어집니다. 화면 위 ← 버튼만 확인을 묻습니다. "나갈까요?" 확인창에서 취소하려고 뒤로가기를 눌러도 나가집니다.
- 원인: 주소가 바뀌면 고친 내용이 있는지 보지 않고 바로 다른 화면을 그립니다. `index.html:813-818`, `index.html:974`. 확인은 ← 버튼(`index.html:2094-2098`)에만 있습니다.
- 고치는 방향: 고친 내용이 있는데 편집 주소를 벗어나면, 주소를 되돌리고 확인창을 띄웁니다.

**3. 뒤로가기로 편집을 나온 뒤에도 버린 초안이 남아 실제 데이터를 덮어씀**
- 상황 가: 계산기 화면에서 Ctrl+S를 누르면 버린 줄 알았던 변경이 "저장했어요"와 함께 저장됩니다(실제로 눌러 확인).
- 상황 나: 계산기 화면에서 "+ 추가"로 품목을 등록한 뒤 다시 편집에 들어가면 그 품목이 목록에 없고, 그대로 저장하면 지워집니다.
- 상황 다: 다시 편집에 들어가면 지난번에 버린 변경이 그대로 나타납니다.
- 원인: 계산기 화면을 그릴 때 편집 상태를 비우지 않고, 같은 편집 주소로 다시 오면 남은 초안을 다시 씁니다. `index.html:931-937`, `index.html:2396`, `index.html:2077`
- 고치는 방향: 편집 화면이 아닌 곳을 그릴 때 편집 상태를 항상 비우고, Ctrl+S는 편집 화면에서만 받습니다.

**4. 계산기에 다시 들어오면 누른 숫자가 기존 값 앞에 붙음**
- 상황: 어제 "10"을 넣어 둔 계산기에 들어와 키패드 5를 누르면 "510"이 되고, 결과도 바로 그 값으로 바뀝니다(PC와 휴대폰 크기 모두 실제로 확인). 키패드 숨기기, 품목 고르기, 품목 바로 추가, 행 삭제 뒤에도 같은 일이 생깁니다.
- 원인: 화면을 다시 그린 뒤 입력칸의 커서 위치를 정하지 않아 맨 앞에 숫자가 들어갑니다. `index.html:1361-1363`, `index.html:1708-1711`
- 고치는 방향: 다시 그린 뒤에는 커서를 끝에 두거나 값을 전체 선택해, 바로 덮어쓸 수 있게 합니다.

**5. 카드 메뉴의 "앞으로 이동 / 뒤로 이동"이 묶음 안에서 움직이지 않음**
- 상황: 처음 깔았을 때 들어 있는 예제 그대로에서 "원단 길이-무게 변환기"의 ⋯ → "뒤로 이동"을 눌러도 카드가 제자리입니다. 각 묶음의 맨 앞 카드에도 "앞으로 이동"이 뜹니다.
- 원인: 순서를 화면에 보이는 묶음 안이 아니라 전체 계산기 목록에서 바꿉니다. 옆 칸이 다른 묶음이면 화면은 그대로입니다. `index.html:1198-1203`, `index.html:1209-1210`
- 고치는 방향: 같은 묶음 안에서 바로 옆 카드와 자리를 바꾸고, 메뉴 표시 기준도 그 목록으로 맞춥니다.

### 낮음: 작은 불편

- **뒤로가기 헛누름:** 편집 화면에서 삭제한 뒤나 없는 계산기 주소로 들어온 뒤, 뒤로가기 1~2번이 반응하지 않음 (`2241`, `804-808`, `815`)
- **홈 복귀:** 계산기에서 홈으로 오면 항상 맨 위로 가고 검색어가 지워짐 (`952`, `1021`)
- **입력 중인 창:** 바깥 누르기·Esc로 새 묶음 이름, 새 품목, 엑셀 붙여넣기 내용이 확인 없이 사라짐 (`855`, `2394`)
- **단축키:** 창이 열린 채 Ctrl+S를 누르면 브라우저 저장 창이 뜸. Caps Lock이 켜져 있으면 저장 안 됨 (`2395-2396`)
- **설치 표시:** 이미 설치한 앱에서도 메뉴에 "앱으로 설치하기"가 보임. 이름이 "앱 설치"와 "앱으로 설치하기"로 갈림 (`1243`, `1137`)
- **백업 안전성:** 내보내기 성공 알림이 실제 다운로드와 무관하게 뜸(추정). 저장 데이터가 깨지면 안내 없이 예제로 바뀌고 덮어씀. 불러올 파일 검사가 얕음. 주소에 잘못된 `%`가 있으면 빈 화면 (`1264-1266`, `741-746`, `1268-1273`, `820`)
- **창 접근성:** Tab 키로 창 뒤 화면까지 이동됨 (`842-870`)
- **묶음:** 새 묶음은 같은 이름을 막지 않음(이름 바꾸기는 막음). "새 묶음 만들어 이동" 안내가 다른 안내에 덮임. 종류 고르기를 닫아도 미리 채울 묶음 값이 남음. 묶음 이름 `__none`이 미분류와 섞임. 계산기 0개일 때 빈 화면 안내가 겹침 (`1057`, `1080`, `1109`, `1116`, `1178`, `749`, `990`, `1028`)
- **홈 버튼:** "백업" 버튼이 백업 창이 아니라 항목 7개짜리 일반 메뉴를 엶. 검색칸 오른쪽 동그라미 아이콘은 기능이 없음. 카드 ⋯ 버튼(34px)과 묶음 +·⋯ 버튼(36px)이 권장 크기 44px보다 작음 (`1014`, `1021`, `165`, `203`)
- **편집기 줄 작업:** 줄을 위·아래로 옮기거나 지운 뒤 커서가 사라지거나 맨 위로 튐. 줄 추가 뒤 새 줄로 스크롤되지 않음. 줄 삭제에 되돌리기가 없음 (`2285-2292`, `1868-1871`)
- **수식형 키:** 입력 키를 바꾸거나 지워도 식은 그대로라 오류만 뜸. 중복 키·잘못된 키는 저장할 때만 알 수 있음. 키 앞뒤 공백 처리가 실시간 검사와 저장 검사에서 다름 (`1972`, `2037-2040`, `2327`)
- **엑셀 붙여넣기:** 인식 못 한 줄을 알리지 않음. `1000/80` 같은 식 값은 거부함. 3열을 복사하면 이름에 단위가 섞임. 같은 이름은 말없이 값을 덮어씀 (`2139-2149`, `2125-2129`)
- **입력 검사 빈틈:** 기준값 0·음수, 함량 100% 초과, 같은 품목 이름 중복(계산기 화면의 빠른 등록은 막음), 함수에 넣는 값 개수를 검사하지 않음 (`2007-2030`)
- **편집기 기타:** 소수 자리수 버튼이 끝값(0·8)에서도 "고친 상태"를 만듦. 6~8에서는 미리보기 숫자가 변하지 않음. 단위를 바꿔도 아래 안내 문장은 옛 단위로 남음. 한글 입력 중 Enter를 누르면 칸을 하나 더 건너뛸 수 있음(추정). 변수 칩을 처음 누르면 식 맨 앞에 들어갈 수 있음(추정) (`2253-2258`, `1901`, `2386`, `2152`)
- **계산 화면:** 품목·입력이 0개인 계산기에서도 키패드가 보이지만 눌러도 반응 없음. 결과를 낼 수 없을 때 이유 없이 "0" 또는 "—"만 보임. 키보드로 `=`를 치면 입력 오류가 남. 환산형에서 Enter를 누르면 계산된 쪽 칸으로 넘어가 계산 방향이 뒤집힘 (`1354`, `1591`, `1632`, `2378`, `2383-2384`)
- **휴대폰 화면:** 375×812 화면에서 키패드 마지막 줄(0 . =)이 화면 밖에 있음. 아이폰 숫자 키보드에는 + − / 키가 없음(추정) (`335`, `1367`)
- **문구 오류:** "새 원료으로 등록"(→ "원료로") (`1518`)

## 3. 설계가 합리적인지

### 3-1. 앱 목적("원하는 대로 계산기를 직접 만든다")이 반영되어 있는지

**판단: 정해진 세 가지 틀 안에서 값과 식을 채우는 수준까지는 잘 되어 있습니다. "원하는 대로"에는 아직 못 미칩니다.**

잘된 점
- 만들기 진입이 가깝습니다. 홈 위쪽의 큰 "새 계산기" 버튼, 종류 선택, 저장까지 3번이고, 저장하면 바로 그 계산기로 넘어갑니다.
- 세 틀(환산·수식·배합)이 사용자의 실제 업무(원단 길이-무게, 고형분, 배합 고형분)와 잘 맞습니다.
- 수식형은 입력칸과 식을 자유롭게 정의할 수 있습니다. 입력하는 동안 "✓ 올바른 식"으로 바로 검사하고, 변수 버튼으로 식을 조립하며, 한글 키 이름도 쓸 수 있습니다.
- 쓰다가 바로 고치는 길이 많습니다. 계산 화면의 연필, "베이스 데이터 관리", "+ 추가", 검색 목록의 "새로 등록"이 있습니다.
- 엑셀 두 열 붙여넣기, 초성 검색, 묶음 정리처럼 품목이 많은 업무를 고려한 기능이 있습니다.

## 4. 사용자 규칙과 맞지 않아 보이는 곳

- **화면 문구의 "~해요"체: 약 69줄.** 종류 설명("~환산해요/만들어요/계산해요"), 알림("저장했어요", "복사했어요"), 빈 화면("아직 계산기가 없어요"), 수식 오류("')' 가 필요해요"), 안내("입력칸에 10+5 같은 식을 써도 계산돼요") 등입니다. 명사형("저장 완료", "검색 결과 없음")이나 "~합니다"로 바꿔야 규칙에 맞습니다.
- **질문형 제목:** "어떤 계산기를 만들까요?"(`1185`) → "계산기 종류 선택". "저장하지 않고 나갈까요?"(`2096`)도 있습니다.
- **"~하세요" 명령형: 약 30곳.** 예: "계산기 이름을 입력하세요", "값을 입력하세요". 금지 목록에 직접 있지는 않지만 "설명은 ~합니다" 기준과 다릅니다.
- **같은 정보를 두 번 표시:** 묶음 탭과 묶음 제목 모두에 계산기 개수가 붙어, 묶음 하나만 볼 때 같은 숫자가 두 번 나옵니다(`980`, `984`). 카드 아래 줄의 "품목 2개" 같은 개수 표시는 제목 줄이 아니라서 판단이 필요합니다.
- 출처·외부 링크와 AI 모델 이름은 없습니다.
